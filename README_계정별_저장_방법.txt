XI:ON ST1 / ST2 계정별 저장 수정

RFID 89BC3C8E → ST1 (A) → 현재 로그인한 ST1 계정에 claimed로 저장
RFID 87BC3C8E → ST2 (B) → ST2 계정에 pending으로 전송, ST2가 로그인하여 가져오기 승인

1. 기존 사이트 백업 후 ZIP의 웹 파일들을 GitHub Pages 저장소 루트에 덮어씁니다.
2. Arduino 파일은 동일하며, 이전 2분 교대 펌웨어를 사용합니다.
3. ST1 계정으로 로그인하여 ST2 닉네임을 선택하고 대시보드에 입장합니다.
4. 교육 시작 → ST1 태깅 및 측정 → 2분 후 ST2 태깅 및 측정 → 교육 종료합니다.
5. ESP32 연결 → 교육 결과 불러오기 → ST1·ST2 각 계정에 기록 저장 버튼을 한 번 누릅니다.
6. ST1 데이터는 ST1 계정에 저장되며 ST2 데이터는 ST2 계정 수령 대기에 전송됩니다.
7. ST2 계정으로 로그인해 내 기록 수령 대기에서 가져오기를 누릅니다.
8. 저장 실패한 쪽만 재시도할 수 있으나, 브라우저 새로고침 이후에는 중복 저장 방지 상태가 초기화됩니다.

주의: 1회차/2회차라는 표현은 첫 번째/두 번째 수행자(ST1/ST2)를 뜻합니다.
센서 RAW 통계이며 CPR 평가지표로 자동 환산되지 않습니다.
기존 Firebase 규칙은 ble_raw를 허용하는 통합본 규칙을 유지하세요.
