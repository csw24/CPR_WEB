XI:ON 누적 교육 결과 BLE 연동 버전

1. ZIP 압축 해제 후 웹 파일들을 GitHub CPR_WEB 저장소 최상위에 올리세요.
2. 기존 사이트의 디자인/로그인/기록 기능은 유지합니다.
3. ESP32에는 기존 Final_Integrated_Sensor_Code_1114_BLE.ino가 설치되어 있어야 합니다.
4. 택트 스위치 첫 번째 누름 -> 교육 시작, 두 번째 누름 -> 교육 종료.
5. 웹에서 ESP32 연결 -> 교육 결과 불러오기.
6. 원시값 요약 표 및 ToF 최소/평균/최대 그래프가 나타납니다.

주의: 이 버전의 BLE 원시값은 학생별 A/B 구분, 압박 깊이(cm), 압박 속도, 이완율, 인공호흡 횟수를 계산할 수 없습니다. 따라서 기존 CPR 평가 카드와 Firebase 기록 저장 버튼은 실제 BLE 결과만으로 채우지 않습니다. 별도 신호 처리/센서 보정/교대 구분 구현이 필요합니다.
ESP32 전원을 끄거나 다음 교육을 시작하면 직전 세션 결과가 사라질 수 있으므로 종료 후 즉시 불러오세요.
